# 奶蛙忍者

在线游玩：https://tekdc47-max.github.io/frog-slice/

鼠标划过即可切，手机手指划动。60 秒一局，R 重开，空格暂停。

- 高级奶娃尺寸更小，切中依次获得 10–110 分。
- 漏切 −5 分，炸弹 −100 分，游戏继续，允许负分。
- 底部不同位置抛出，自然弧线飞行，每波上限 2–5 个目标，随难度提高；生成前检查轨迹安全间距。
- 发光星点光标与金色划切轨迹；连续切中有连击奖励。
- 难度随时间递增，每 15 秒显示一个阶段；飞行速度、出场频率、高级奶娃和多目标比例平滑提高，每波上限从 2 个逐步提高到 5 个目标。
- 划切使用完整连续路径，补偿目标运动，支持鼠标合并采样，快速横向划切也能命中。
- 最高分与最近记录只保存在当前浏览器。

`index.html` 是包含图片和脚本的完整网页，下载后可直接打开。`frog-slice.zip` 包含分文件源码、素材和检查脚本。

角色图片来自用户指定的原游戏：https://yhsome.github.io/BigNaiWa/v1/ 。游戏与界面代码为新实现，玩法参考 Fruit Ninja。原角色素材的权利归各自权利人，本仓库不为其另行授权。
