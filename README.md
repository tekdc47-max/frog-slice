# 奶蛙忍者

打开 index.html 可直接游玩；也可以在此目录运行 `node server.cjs`，浏览器打开 http://localhost:4173。

鼠标划过即切，无需按住；触屏划动。60 秒一局，R 重开，空格暂停。

开始前选择简单、困难、地狱。简单速度更慢、最多 3 个目标；困难保留原节奏；地狱速度更快，高级奶娃、炸弹和密集目标更多。每个难度分别保存最近 10 局记录与永久最高分；原版记录迁移到困难。数据仅保存在当前浏览器。

发光星点光标跟随鼠标，带金色划切轨迹。每波最多 2–5 个目标，随难度提高，初始重力为 1000 px/s²，随难度提高，角色从底部和左右侧不同位置抛出，带自然向内的弧线，预先检查整段轨迹避免重合；新一波等待上一波角色及碎片离场，旋转图片也保留安全间距。

运行 `node check.cjs` 检查抛出数量、旋转后的安全间距和划线命中几何。

难度随时间递增，每 15 秒显示一个阶段，飞行速度、出场频率、高级奶娃和多目标比例平滑提高。每波上限从 2 个逐步提高到 5 个目标。连续划线会补偿奶娃运动并处理鼠标合并采样，改善快速横向划切的命中。

奶娃可以从底部或左右侧斜着飞入。命中区使用图片透明度生成的区域并跟随旋转，覆盖可见边缘；裂缝沿着鼠标划线方向，两半向裂缝的两侧飞散。

11 级角色对应原网页的 11 张图片，等级越高尺寸越小，切中得分依次为 10–110 分。漏切 −5 分，炸弹按难度扣分：简单 −100、困难 −200、地狱 −500 分，允许负分；连续 0.48 秒内切中，第二只起额外奖励。最高分与最近 10 局记录存在当前浏览器。

角色素材来源：https://yhsome.github.io/BigNaiWa/v1/ 。玩法参考用户提供的 Fruit Ninja 页面。页面和游戏代码为本项目新实现。若公开发布，请确认原素材的使用许可。






开始前可调鼠标灵敏度（0.5×–3.0×），默认 1.0×。数值越高，奶娃边缘的命中容差越大；鼠标位置、光标大小与炸弹命中范围不变。设置保存在当前浏览器，可一键恢复默认。

左右侧飞入的奶娃在中间平滑减速（中心瞬时速度约为原来的 42%），移动和下落一起放慢，离开中间后自然加速。轨迹间距预判同步使用该运动曲线，保持奶娃与炸弹的安全间距。

2026-10-19：参考水果忍者公开发布脚本的刀光逐帧检测方式，奶蛙在划切后 100 毫秒内仍可被短刀光切中；断开和重新进入的鼠标轨迹不会连接，炸弹仍只按直接划切判定。侧边抛物线的顶点调整到画面中央，并保留额外减速。本站使用自己实现的 Canvas 代码。
